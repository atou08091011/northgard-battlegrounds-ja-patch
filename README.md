## ✨ 主な機能

- ゲーム内テキストを日本語化
- 日本語フォントに対応
- メニュー、チュートリアル、カードやスキルの説明などを日本語で表示

## 🔧 インストール方法

1. 上記のリンクから、対応する日本語化パッチをダウンロードします。
2. ZIPファイルの場合は解凍し、インストーラー（EXE）を実行します。
3. 画面の案内に従ってインストールします。
4. インストール完了後、ゲームを起動してください。

※インストールの詳細は、各バージョンのReleaseページをご確認ください。
